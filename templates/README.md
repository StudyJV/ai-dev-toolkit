# Team starter templates

Copy a folder into your repo and adjust the data paths. Each template is a thin
wrapper over an existing tool with a runnable script and a review checklist.

- [`cost-review-starter`](./cost-review-starter/README.md) - weekly LLM spend review with `llm-cost-observatory`
- [`rag-eval-starter`](./rag-eval-starter/README.md) - RAG quality gate with `rag-debug-kit`

Both scripts assume this repo layout (`tools/*`). If you vendor a template
elsewhere, point the `--store` and tool paths at your checkout.
